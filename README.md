# SkyCore

Компактный космический симулятор-песочница для ESP32-S3 и монохромного OLED-дисплея 128×64. Вдохновлён KSP, Spaceflight Simulator и Juno: New Origins.

Игра умещается на плате ESP32-S3 DevKitC-1 (63×26 мм) вместе с OLED, стиком и зуммером. Аналоговое управление, физика орбит, миникарта с предсказанием траектории, меню настроек, мировая карта и фоновая музыка в реальном времени.

---

## Что уже работает

- **Физика орбит** — обратно-квадратичная гравитация `g = g₀ · (R/r)²`, настоящие эллипсы и замкнутые орбиты
- **Аналоговое управление** — стик с автокалибровкой (центр + размах по обеим осям)
- **Поворот ракеты** — стик влево/вправо, тяга вдоль носа
- **Аналоговый газ** — стик вниз, S-кривая для плавности, мощность пропорциональна отклонению
- **Миникарта** — планета, орбита, трейл прошлого, предсказание будущего
- **Мировая карта** — отдельный экран, камера привязана к кораблю, низ всегда мировой
- **Линия Кармана** — переход локальной/мировой вертикали камеры
- **Меню настроек** — три вкладки (САС, Осн, Физ) с разными типами значений
- **Музыка** — фоновая мелодия планеты, орбитальный эмбиент, эпик при выходе из атмосферы, тон двигателя
- **HUD** — топливо, высота, вертикальная скорость
- **Serial-лог** — статус раз в секунду + события. Не спамит, потому что мы уважаем твой терминал
- **Модульная структура** — 24 файла в отдельных папках, а не один giant main.cpp
- **Файл `language.h`** — все надписи в одном месте, чтобы перевести или переименовать за 30 секунд

## Железо

| Компонент | Модель | Примечание |
|---|---|---|
| Микроконтроллер | ESP32-S3 DevKitC-1 (модуль WROOM-1, R8N16) | 8 МБ PSRAM, 16 МБ flash |
| Дисплей | SSD1306, 128×64, I2C | Адрес `0x3C` |
| Стик | Аналоговый, 2 потенциометра + кнопка | С кнопкой по центру |
| Зуммер | Пассивный, 3 пина (S / VCC / GND) | Через LEDC (PWM) |
| Переключатели | 2 тактовые кнопки | Для переключения режимов |

### Распиновка

| Устройство | Пин ESP32-S3 |
|---|---|
| SSD1306 — SDA | GPIO 5 |
| SSD1306 — SCL | GPIO 4 |
| Стик — VRx | GPIO 6 |
| Стик — VRy | GPIO 7 |
| Стик — SW (кнопка) | GPIO 16 |
| Зуммер — S | GPIO 15 |
| Меню (SW) | GPIO 17 |
| Мировая карта (SW) | GPIO 18 |

**Переключатели режима:** замкни GPIO 17 на GND — попадёшь в меню. GPIO 18 — в мировую карту. Оба висят в воздухе — обычный полёт.

## Сборка

### Требования

- [VS Code](https://code.visualstudio.com/)
- [PlatformIO](https://platformio.org/install/ide?install=vscode) — расширение для VS Code
- Git

### Шаги

1. Клонируй репозиторий:
```

git clone https://github.com/Shadow-okak/skycore.git

```
2. Открой папку `skycore` в VS Code.
3. Дождись, пока PlatformIO скачает зависимости (первый раз 5–15 минут).
4. В левой панели PlatformIO нажми **Build**, затем **Upload**.
5. Если прошивка не заливается — зажми кнопку **BOOT** на плате, нажми Upload, отпусти через секунду.

> **Совет:** если плата не входит в режим прошивки с первого раза — зажми BOOT, нажми RESET, отпусти RESET, отпусти BOOT, посмотри на плату осуждающе, повтори. Работает в 80% случаев.

> **Важно:** путь к проекту **не должен содержать кириллицу**. `C:\Users\Пользователь\...` сломает сборку — линкер ESP-IDF не умеет с не-ASCII. Перенеси проект в `C:\Projects\skycore` или аналог.

### Serial-монитор

В PlatformIO нажми иконку **Serial Monitor** (или открой порт 115200 в любом терминале).

При старте:
```

=== SkyCore ===
Ускорение времени: x3
Калибровка: cx=1835 cy=1912 rx=2260 ry=2183
Игра запущена. Жду событий...

```

Далее — строка статуса раз в секунду:
```

[ST] alt=110м  v=16.0  вл=-0.9  угол=344°  топ=73%

```

И события по мере их появления:
```

[EV] Посадка  v=13.4 м/с
[EV] Тяга включена  65%
[EV] Топливо кончилось

```

## Управление

| Действие | Что делает |
|---|---|
| Стик влево / вправо | Поворот ракеты (против / по часовой) |
| Стик вниз | Газ. Чем дальше вниз — тем сильнее тяга |
| Стик отпущен | Ракета летит по инерции в поле гравитации |
| Кнопка стика | Завершение калибровки при старте |
| GPIO 17 на GND | Меню настроек |
| GPIO 18 на GND | Мировая карта |

### Калибровка при запуске

1. **Фаза 1/2** — отпусти стик, ждём 0.5 секунды. Замеряется центр покоя.
2. **Фаза 2/2** — води стик по максимумам во все стороны. На экране видно `X:min-max`. Когда обошёл все края — **нажми кнопку стика**. Калибровка сохранится, игра запустится.

> **Важно:** на фазе 2/2 крути стик **до упора во все стороны**. Если покажется, что «и так сойдёт» — сойдёт, но ракета будет медленно уползать в сторону. Так задумано природой стиков.

### Меню

Навигация стиком:
- **↑↓** — листать вкладки (САС / Осн / Физ)
- **→** — войти в правую панель настроек
- **↑↓** — листать настройки, **←** — назад
- **→** на BOOL/ENUM — мгновенно меняет значение
- **→** на INT/FLOAT/PERCENT — вход в редактирование, **↑↓** меняет, **←** выход

## Физика

- **Гравитация:** `g(r) = g₀ · (R/r)²`, где `g₀ = 8 м/с²` на поверхности, `R` — радиус планеты.
- **Интеграция:** метод Эйлера, шаг `1/60` секунды.
- **Ускорение времени:** `SPEED_MULT = 3` (можно менять в `config.h`).
- **Коллизия:** радиус корабля 5 пикселей. Радиальная скорость гасится, тангенциальная — трением (`0.9` за шаг), чтобы не скользить по поверхности.
- **Предсказание орбиты:** 2000 шагов вперёд без учёта тяги, пересчёт 10 раз в секунду.

## Музыка

- **Планета** — тёплая минорная пентатоника, играет на поверхности и в атмосфере, зацикливается.
- **Орбита** — редкие высокие ноты, эмбиент, играет выше линии Кармана.
- **Выход из Кармана** — восходящее мажорное арпеджио на 5 секунд, эпик в момент пересечения границы вверх.
- **Двигатель** — тон 200–800 Гц, растёт с газом. Перебивает всё остальное.
- **После отпускания газа** — фон начинается заново с начала.

Все мелодии — массивы `{ частота_Гц, длительность_мс }` в `audio/music.cpp`. Менять легко.

## Второй игрок (в планах)

Для мультиплеера по ESP-NOW подойдёт **ESP32-C3 Super Mini** — маленькая, дешёвая, с WiFi. Не пытайся запихнуть в неё саму игру: у неё 400 КБ ОЗУ против 8 МБ PSRAM у S3. Она — для второго пульта.

*Покупай C3 заранее, чтобы к моменту релиза мультиплеера уже лежала в ящике и грустно смотрела на тебя.*

## Участие

Проект задуман как командный. Вклад приветствуется:

1. Форкни репозиторий.
2. Создай ветку под свою задачу: `git checkout -b feat/my-feature`.
3. Закоммить изменения: `git commit -m "feat: описание"`.
4. Запушь: `git push origin feat/my-feature`.
5. Открой Pull Request.

Стиль коммитов — [Conventional Commits](https://www.conventionalcommits.org/):
- `feat:` — новая функция
- `fix:` — исправление бага
- `docs:` — документация
- `refactor:` — рефакторинг без смены поведения
- `chore:` — прочее (конфиги, обновления)

## Правила эксплуатации

1. **Работает — не трогай.**
2. **Не работает — сам дурак.** Но если серьёзно: проверь питание, потом пины, потом ещё раз питание. В 90% случаев помогает перезалить прошивку.
3. **Работает, но странно** — это фича, а не баг. Ты просто ещё не понял замысел.
4. **Залил прошивку — сломалось** — откатись на предыдущий коммит и сделай вид, что так и было.
5. **Помогло** — молодец. **Не помогло** — см. пункт 2.
6. **README в 01:16** — это нормально. Ночные README самые честные.
