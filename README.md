# SkyCore

Компактный космический симулятор-песочница для ESP32-S3 и монохромного OLED-дисплея 128×64. Вдохновлён KSP, Spaceflight Simulator и Juno: New Origins.

Игра умещается на плате ESP32-S3 DevKitC-1 (63×26 мм) вместе с OLED, стиком и зуммером. Аналоговое управление, физика орбит, миникарта с предсказанием траектории, меню настроек, мировая карта и фоновая музыка в реальном времени.

---

## Что уже работает

- **Физика орбит** — обратно-квадратичная гравитация `g = g₀ · (R/r)²`, настоящие эллипсы и замкнутые орбиты
- **Аналоговое управление** — стик с автокалибровкой (центр + размах по обеим осям)
- **Поворот ракеты** — стик влево/вправо, тяга вдоль носа
- **Аналоговый газ** — стик вниз, S-кривая для плавности, мощность пропорциональна отклонению
- **Миникарта** — планета, орбита, трейл прошлого, предсказание будущего
- **Мировая карта** — отдельный экран, камера привязана к кораблю, низ всегда мировой
- **Линия Кармана** — переход локальной/мировой вертикали камеры
- **Меню настроек** — три вкладки (САС, Осн, Физ) с разными типами значений
- **Музыка** — фоновая мелодия планеты, орбитальный эмбиент, эпик при выходе из атмосферы, тон двигателя
- **HUD** — топливо, высота, вертикальная скорость
- **Serial-лог** — статус раз в секунду + события. Не спамит, потому что мы уважаем твой терминал
- **Модульная структура** — 24 файла в отдельных папках, а не один giant main.cpp
- **Файл `language.h`** — все надписи в одном месте, чтобы перевести или переименовать за 30 секунд

## Железо

| Компонент | Модель | Примечание |
|---|---|---|
| Микроконтроллер | ESP32-S3 DevKitC-1 (модуль WROOM-1, R8N16) | 8 МБ PSRAM, 16 МБ flash |
| Дисплей | SSD1306, 128×64, I2C | Адрес `0x3C` |
| Стик | Аналоговый, 2 потенциометра + кнопка | С кнопкой по центру |
| Зуммер | Пассивный, 3 пина (S / VCC / GND) | Через LEDC (PWM) |
| Переключатели | 2 тактовые кнопки | Для переключения режимов |

### Распиновка

| Устройство | Пин ESP32-S3 |
|---|---|
| SSD1306 — SDA | GPIO 5 |
| SSD1306 — SCL | GPIO 4 |
| Стик — VRx | GPIO 6 |
| Стик — VRy | GPIO 7 |
| Стик — SW (кнопка) | GPIO 16 |
| Зуммер — S | GPIO 15 |
| Меню (SW) | GPIO 17 |
| Мировая карта (SW) | GPIO 18 |

**Переключатели режима:** замкни GPIO 17 на GND — попадёшь в меню. GPIO 18 — в мировую карту. Оба висят в воздухе — обычный полёт.
